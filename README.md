## Personal project: Chatalog

[Chatalog](https://chatalog.com.ua) is a self-hosted platform for small stores that sell through TikTok, Instagram and Telegram. I built it for our family clothing store and designed it to host many stores: each has its own catalog, orders, team, Telegram bot and API keys.

- Live store on it: [adeli-mood.chatalog.com.ua](https://adeli-mood.chatalog.com.ua)
- Demo storefront with invented data: [demo.chatalog.com.ua/shop/lumi_studio](https://demo.chatalog.com.ua/shop/lumi_studio) (runs on my own hardware, may occasionally be offline)
- Mobile-first back office (installable PWA), Telegram Mini App storefront, Nova Poshta delivery, Telegram bot notifications
- Stack: TypeScript, Next.js, React, Tailwind CSS, Express, PostgreSQL, Docker
- The production code is private. A trimmed, open-source demo of its core (tenant isolation, stock, orders, tests, CI) is here: [storekit](https://github.com/max-shlikhta/storekit)
